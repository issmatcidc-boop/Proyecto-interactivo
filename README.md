# Proyecto-interactivo
# 🏆 DASH SOUND: TORNEO < vs U
**Proyecto Interactivo Unidad 1: Taller de Interfaces**

## 📝 Descripción del Proyecto
Dispositivo de Interfaz Sonora Tangible basado en la experiencia del Museo Interactivo Mirador (MIM). El proyecto transforma un juego tradicional de pulso/fuerza ("gallito") en una experiencia audiovisual mediante la técnica de **keyboard hack**, reemplazando las teclas convencionales por un mecanismo de contacto físico artesanal que interactúa en tiempo real con una interfaz web.

---

## 🛠️ Archivos de Código y Proceso

* **`index.html`**: Código fuente completo de la interfaz, estructurado con HTML5, CSS3 y Vanilla JavaScript. Contiene la lógica del sistema de puntuación, la detección de eventos del teclado (`keydown`), la gestión de estados de victoria y el diseño del menú de navegación.
* **Archivos de Sonido**: 
  * `Moneda de Mario Bros [ Download ]_2.mp3` (Feedback auditivo por cada pulsación válida).
  * `Fatality_2.mp3` (Feedback auditivo gatillado al alcanzar la condición de victoria).
* **Registro Audiovisual y Lámina**: El repositorio incluye los videos del proceso de construcción (`procesopt1.mp4`, `procesopt2.mp4`), el video demostrativo final (`video.mp4.mp4`) y la lámina de presentación (`lamina.jpg`), los cuales se pueden visualizar directamente desde la aplicación web o en la carpeta raíz.

---

## 🚀 Instrucciones de Uso
1. Abre el repositorio en un navegador web o clónalo localmente.
2. Ejecuta el archivo `index.html` para acceder al menú principal.
3. Utiliza los botones superiores para alternar entre la **Documentación** y el **Jugar Torneo**[cite: 3].
